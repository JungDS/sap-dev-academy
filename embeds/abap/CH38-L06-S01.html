BAL 3박자 — 부분을 클릭

밑줄 부분을 클릭해 역할을 확인한 뒤, 고장 카드 4장으로 무엇을 빠뜨리면 무엇이 사라지는지 판별하세요.

야간 정산 로그 남기기 (본문 코드 축약)
gs_log-object    = 'ZBOOK'.
gs_log-subobject = 'SETTLE'.
gs_log-extnumber = 'RUN-20260801-020000'.
CALL FUNCTION 'BAL_LOG_CREATE'
  EXPORTING i_s_log      = gs_log
  IMPORTING e_log_handle = gv_handle.

CALL FUNCTION 'BAL_LOG_MSG_ADD'
  EXPORTING
    i_log_handle = gv_handle
    i_s_msg      = VALUE bal_s_msg(
      msgty = 'E'  msgid = 'ZBOOK'  msgno = '001'
      msgv1 = '0001' ).   " 실패한 예매의 key

CALL FUNCTION 'BAL_DB_SAVE'
  EXPORTING i_save_all = abap_true.
COMMIT WORK.                       " 저장 확정(CH25 LUW)
밑줄 친 구문을 클릭해 보세요.
🚨 고장 카드를 클릭하면 무엇이 사라지는지 나옵니다.
💡 3박자 = 생성(CREATE) → 담기(MSG_ADD 반복) → 저장(DB_SAVE). 저장 전까지는 전부 메모리 위의 이야기입니다.
