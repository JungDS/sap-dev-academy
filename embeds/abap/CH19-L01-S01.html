Classic → Modern SQL (콤마 · @ · INTO 뒤로)

같은 SELECT를 한 단계씩 모던으로 바꿔 보세요. 콤마로 필드를 나누고, @로 ABAP 변수를 표시하고, INTO를 맨 뒤로 옮깁니다. 항공사 코드를 바꿔도 표기만 달라질 뿐 결과(행 수·sy-subrc·sy-dbcnt)는 같습니다.

변환 단계
항공사 코드(@lv_carr)

SELECT 코드

실행 결과 (classic·완성형 기준 — 중간 단계는 참고용)

핵심. modern SQL은 "더 짧은 문법"이 아니라 ABAP 변수(@)와 DB 컬럼의 경계를 분명히 표시하는 방식입니다. DB 컬럼엔 @를 붙이지 않고, INTO는 마지막에 둡니다.
