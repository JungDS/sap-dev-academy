ZI_Booking BDEF (본문 코드 축약)
managed implementation in class zbp_i_booking unique;
strict ( 2 );
with draft;

define behavior for ZI_Booking alias Booking
persistent table zbooking
draft table zbooking_d
lock master
total etag LastChangedAt
etag master LastChangedAt
authorization master ( global, instance )
{
  create; update; delete;
  validation validateCapacity on save { field Seats; }
  action ( features : instance ) cancelBooking result [1] $self;
  draft action Edit; draft action Resume;
  draft action Activate optimized; draft action Discard;
}
밑줄 친 조항을 클릭해 보세요.
🚨 계약 누락 카드를 클릭하면 무슨 일이 나는지 나옵니다.
💡 입문 BDEF(CH24)와의 차이 = Draft·total etag·authorization 조항. 계약이 자리(구현 메서드)를 만들고, 자리는 판단(L05·L08)으로 채웁니다.
