IDoc — 등기우편 같은 3층 봉투

각 층을 클릭해 보세요: 송장(Control)·내용물(Data)·배송 이력(Status). 오류 IDoc 보기에서는 상태(51)와 원인 Segment를 함께 읽는 연습을 합니다.

EDIDCControl Record발신·수신·메시지 타입·방향
EDIDDData Records실제 데이터 — Segment 묶음
EDIDSStatus Records처리 상태 이력
💡 Message Type(ORDERS=업무 의미)과 Basic Type(ORDERS05=구조 버전)은 별개 이름입니다. 장애 분석 = 이력에서 단계 확인 → 내용물에서 원인 값 확인. 상태 코드는 대표값(시스템별 편차 있음).
