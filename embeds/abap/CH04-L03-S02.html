AND · OR · NOT · 괄호 — 여러 조건을 묶는다 (VIP 혜택 판정)

( pa_amt > 5000 OR pa_vip = 'X' ) AND NOT pa_block = 'X'. 괄호부터, 그다음 NOT, 마지막 AND 순으로 봅니다. 세 값을 직접 바꿔 어떻게 판정이 뒤집히는지 확인해 보세요.

① 괄호 안 pa_amt > 5000OR pa_vip = 'X'→
② NOT pa_block = 'X'→ 뒤집으면
③ AND ① 과 ② 가 둘 다 참인가?

ABAP · 위 판정을 그대로 옮긴 코드
PARAMETERS: pa_amt   TYPE i,
            pa_vip   TYPE c LENGTH 1,    " VIP 회원이면 'X'
            pa_block TYPE c LENGTH 1.    " 거래 정지면 'X'

IF ( pa_amt > 5000 OR pa_vip = 'X' ) AND NOT pa_block = 'X'.
  WRITE: / 'VIP 혜택'.
ENDIF.

섞이면 괄호로 의도를 분명히 합니다. 괄호 안 OR(하나라도)를 먼저 묶고, NOT으로 차단을 뒤집은 뒤, AND로 둘을 모두 요구합니다. 괄호 안쪽도 ( pa_amt > 5000 )처럼 앞뒤 공백을 둡니다.
