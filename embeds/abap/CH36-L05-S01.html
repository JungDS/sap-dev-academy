CDS Table Function — 세 조각 연결 지도

단계 버튼을 순서대로 눌러 DDL(계약) → AMDP 클래스(몸) → SELECT(소비)가 어떻게 이어지는지 확인하세요.

CDS DDL (계약)
define table function
  ZTF_BOOKING_STAT
with parameters
  p_client : abap.clnt, …
returns { client; concert_id;
          booking_cnt; total_seats; }
implemented by method
  zcl_booking_tf=>get_stat;
⚠ p_client 확인
AMDP 클래스 (몸)
INTERFACES if_amdp_marker_hdb.
CLASS-METHODS get_stat
  FOR TABLE FUNCTION
    ztf_booking_stat.
…
METHOD get_stat
  BY DATABASE FUNCTION FOR HDB
  LANGUAGE SQLSCRIPT
  OPTIONS READ-ONLY
  USING zbooking.
  RETURN SELECT … ;
소비 (ABAP SQL / CDS)
SELECT FROM
  ztf_booking_stat(
    p_client = @sy-mandt,
    p_from   = @gv_from,
    p_to     = @gv_to )
  FIELDS concert_id,
         booking_cnt, total_seats
  INTO TABLE @DATA(gt_stat).
💡 핵심: 클래스 메서드를 직접 호출하지 않습니다. CDS Table Function이라는 엔티티를 SELECT하면 뒤에서 AMDP 함수가 DB 안에서 돕니다. (코드는 본문 정본의 축약판)
