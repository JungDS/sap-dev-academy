abap_bool — 참/거짓을 '한 글자'에 담는다 (xsdbool로 채워 보기)

ABAP엔 참/거짓 전용 타입이 없어서 한 글자 문자에 'X'(참)와 공백(거짓)을 담습니다. pa_amt를 움직여, 비교 결과가 gv_flag라는 한 칸에 어떻게 들어가는지 보세요.

① 비교 조건

pa_amt > 1000

거짓

➜

② xsdbool( )이 담는 한 글자

gv_flag

␣

= abap_false (공백)

➜

③ IF gv_flag = abap_true

참인가?

거짓

…

ABAP · 지금 실행 중인 코드
PARAMETERS pa_amt TYPE i.
DATA gv_flag TYPE abap_bool.      " 속은 문자 한 글자

gv_flag = xsdbool( pa_amt > 1000 ).   " 큰 금액이면 'X'
IF gv_flag = abap_true.
  WRITE: / '플래그 켜짐'.
ENDIF.

abap_true는 'X', abap_false는 공백을 담아 둔 이름표(CONSTANTS)입니다. TYPE c LENGTH 1로 적어도 동작은 똑같지만, abap_bool로 적으면 "이 변수는 참/거짓용"이라는 뜻이 코드에 그대로 드러납니다. 값도 'X'를 직접 쓰기보다 abap_true로 쓰는 이유가 같습니다.
