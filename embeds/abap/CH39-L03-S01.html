각 조각이 화면의 어디를 만드는지 확인하세요. 화면을 만들지 "규칙"은 만들지 않는다는 점도.

ZC_Booking + Metadata Extension (축약)
@Metadata.allowExtensions: true
define root view entity ZC_Booking
  provider contract transactional_query
  as projection on ZI_Booking
{
  key BookingId,
      @UI.lineItem: [ { position: 30, label: 'Customer' } ]
      @UI.identification: [ { position: 30 } ]
      Customer,
      Seats, Status, LastChangedAt, _Concert
}

// Metadata Extension (별도 파일)
annotate view ZC_Booking with
{
  @UI.facet: [ { type: #IDENTIFICATION_REFERENCE, ... } ]
  BookingId;
}
밑줄 친 구문을 클릭해 보세요.
💡 lineItem=목록 컬럼 · identification=상세 필드 · facet=상세 구역. facet 없이 identification만 달면 상세 화면이 비어 보입니다.
