PDF 바이트 파이프라인 — 부분을 클릭

밑줄 부분을 클릭해 역할을 확인한 뒤, 아래 고장 카드 4장으로 무엇이 왜 깨지는지 판별하세요.

예매 확인서 PDF 저장 (본문 코드 축약)
" L02의 ④ CONVERT_OTF에서 IMPORTING 한 줄을 추가해 받았다:
"   bin_file = gv_pdf   ← PDF 한 덩어리(xstring)

IF xstrlen( gv_pdf ) = 0.
  " 비었으면 저장이 아니라 생성·변환(양식·L02) 문제부터
  MESSAGE 'PDF가 생성되지 않았습니다' TYPE 'E'.
ENDIF.

gt_bin = cl_bcs_convert=>xstring_to_solix( gv_pdf ).

cl_gui_frontend_services=>gui_download(
  EXPORTING filename     = 'C:\temp\ticket.pdf'
            filetype     = 'BIN'
            bin_filesize = xstrlen( gv_pdf )
  CHANGING  data_tab     = gt_bin ).
밑줄 친 구문을 클릭해 보세요.
🚨 고장 카드를 클릭하면 무엇이 깨지는지 나옵니다.
💡 파이프라인 = 결과 구조 → xstring → (빈 값 검사) → 바이너리 테이블 → BIN 저장. gui_download는 SAP GUI 대화 전용입니다.
