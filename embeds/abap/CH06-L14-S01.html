옛 코드 ↔ 새 코드 — 같은 일, 다른 표기 (Header Line 해독)

왼쪽은 실무에서 마주칠 20년 된 표기, 오른쪽은 이 챕터에서 배운 지금 표준입니다. 줄을 누르면(탭) 서로 대응하는 줄이 함께 빛나고 해독 포인트가 아래에 고정됩니다 — 같은 줄을 다시 누르면 해제, 마우스를 올려 훑어보기만 해도 됩니다. 왼쪽은 읽을 줄만 알면 됩니다 — 새 코드에 쓰면 안 됩니다.

🕰 옛 코드 해독 — 줄을 누르면 설명이 고정됩니다

옛 코드 (읽기 전용 지식)

DATA it_person TYPE TABLE OF ts_person
     WITH HEADER LINE.
DATA: BEGIN OF it_person OCCURS 0,
        name TYPE string,
        age  TYPE i,
      END OF it_person.
it_person-name = '정훈영'.
APPEND it_person.
READ TABLE it_person
     WITH KEY name = '정훈영'.
CLEAR it_person.
CLEAR it_person[].

지금 표준 (이 챕터에서 배운 방식)

DATA: gs_person TYPE ts_person,
      gt_person TYPE TABLE OF ts_person.
TYPES: BEGIN OF ts_person,
         name TYPE string,
         age  TYPE i,
       END OF ts_person.
gs_person-name = '정훈영'.
APPEND gs_person TO gt_person.
READ TABLE gt_person INTO gs_person
     WITH KEY name = '정훈영'.
CLEAR gs_person.
CLEAR gt_person.
줄을 누르면 해독 포인트가 여기 고정됩니다(마우스는 올려 훑어보기만도 OK).
💡 판별 기준은 이름(it_)이 아니라 선언문(WITH HEADER LINE·OCCURS)입니다. 이 표기는 공식적으로 obsolete — 클래스·메서드 안에서는 아예 구문 오류입니다. 여러분은 이미 권장 방식만 배웠습니다.
