Output Control — 언제·무엇을·누구에게 출력하나

양식을 만들었다고 자동으로 나가지 않습니다. 출력 결정이 조건을 보고 양식·채널을 고릅니다.

업무 이벤트 → 출력 결정 → 양식·채널

각 마디가 곧 확인 지점입니다: 이벤트가 있었나 → 결정이 났나(NAST 조건/BRFplus 규칙) → 양식·채널은 맞나 → 렌더링·전달까지 갔나. 마디가 다르면 고칠 곳도 다릅니다.
