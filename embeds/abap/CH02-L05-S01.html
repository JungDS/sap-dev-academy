pi를 직접 적으면 vs 상수 하나로 (같은 계산, 두 버전)

반지름 3과 5인 원의 둘레·넓이를 구하는 같은 계산입니다. pi를 줄마다 직접 적은 쪽(왼쪽)과 상수 gc_pi 하나로 묶은 쪽(오른쪽)을 비교해 보세요.

✗ pi를 줄마다 직접
DATA: gv_c TYPE p LENGTH 8 DECIMALS 2,
      gv_a TYPE p LENGTH 8 DECIMALS 2.

" 반지름 3
gv_c = 2 * '3.1415926' * 3.
gv_a = '3.1415927' * 3 * 3.   " …27 오타!

" 반지름 5
gv_c = 2 * '3.14' * 5.
gv_a = '3.14159' * 5 * 5.
  • 줄마다 pi가 다르다: '3.1415926'·'3.1415927'·'3.14'·'3.14159'
  • 끝자리 오타(…27)·정밀도 불일치로 결과가 미묘하게 틀어진다
직접 적은 pi: 4곳 (다 다름)
✓ 상수 gc_pi 하나
DATA: gv_c TYPE p LENGTH 8 DECIMALS 2,
      gv_a TYPE p LENGTH 8 DECIMALS 2.
CONSTANTS gc_pi TYPE p LENGTH 8 DECIMALS 7 VALUE '3.1415926'.

" 반지름 3
gv_c = 2 * gc_pi * 3.
gv_a = gc_pi * 3 * 3.

" 반지름 5
gv_c = 2 * gc_pi * 5.
gv_a = gc_pi * 5 * 5.
  • gc_pi 하나만 읽어 모든 계산이 같은 값
  • 사람이 잘못 적을 일이 없다(정밀도를 바꿔도 선언 한 줄만)
직접 적은 pi: 0곳
