classic ↔ modern — 같은 로직, 두 표기 (VALUE · +=)

왼쪽 classic 줄을 누르면(탭) 오른쪽 modern 대응 줄이 함께 빛나고, 아래에 무엇이 어떻게 짧아졌는지가 고정됩니다(다시 누르면 해제·마우스 훑어보기도 가능). classic도 현장에 있으니 읽을 줄 알아야 합니다.

🔁 classic ↔ modern — 줄을 누르면 설명이 고정됩니다

classic (개선 전)

DATA ls_book TYPE ts_book.
DATA lt_book TYPE tt_book.
ls_book-concert_id = 'C001'.
ls_book-perf_no    = '001'.
ls_book-seats      = 2.
APPEND ls_book TO lt_book.
lv_total = lv_total + ls_book-seats.

modern (권장)

DATA(lt_book) = VALUE tt_book(
  ( concert_id = 'C001'
    perf_no = '001' seats = 2 ) ).
lv_total += lt_book[ 1 ]-seats.
줄을 누르면 바뀐 이유가 여기 고정됩니다(마우스는 올려 훑어보기만도 OK).
