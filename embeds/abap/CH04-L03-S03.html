IS INITIAL — 변수가 '초기값'인지 묻는다 (빈 값 확인)

pa_amt IS INITIAL은 "값이 아직 비어 있나?"를 묻습니다. 초기값이면 참, 아니면 거짓입니다. 값을 넣어 어느 쪽이 켜지는지 보고, 아래 두 프리셋도 꼭 눌러 보세요.

…

⚠️ 방금 두 가지를 다 눌러 봤나요? 아무것도 입력하지 않아도 0, 0을 직접 입력해도 0입니다. 숫자 변수에서는 IS INITIAL만으로 이 둘을 구분할 수 없습니다.

초기값은 타입마다 다른 '빈 값'입니다: 숫자 0 · 문자 공백 · 날짜 00000000. IS INITIAL은 이 빈 값을 타입에 맞게 한 번에 확인해 줘서 pa_amt = 0보다 깔끔합니다.
