SALV 1차 (간단 ALV)

Internal Table → SALV 미니 리포트

SELECT → SALV까지 한 프로그램으로 — 첫 표 리포트 완성.

Track 1Chapter 11Lesson 4초급

처음부터 끝까지 한 번에

지금까지 배운 걸 모아 DB 조회 → 표 출력까지 하나의 프로그램으로 완성한다. Chapter 08 · SELECT 형태에서 배운 조회와 의 결합이다.

여기서 쓰는 SELECT 표기를 classic이라고 부른다. 지금까지 배운 그 모양 그대로라는 뜻이다. 뒤에 가면 같은 조회를 조금 다르게 쓰는 새 표기(modern)도 나오는데, 그건 Chapter 19 · Classic과 Modern SQL 비교에서 배운다. 지금은 배운 대로 쓰면 된다.

🔎 [선행 사용] 코드 첫머리의 START-OF-SELECTION.은 "여기서부터 실제 처리를 시작한다"고 알리는 표시다. 리포트가 실행되는 순서를 정하는 장치인데, 정식으로는 Chapter 15 · START-OF-SELECTION 조회 실행에서 배운다. 지금은 이 줄 아래에 본 처리를 적는다는 것만 알면 된다(분석·암기 불필요).

REPORT zsalv_flight.

DATA: gt_flight TYPE TABLE OF sflight,
      go_alv    TYPE REF TO cl_salv_table.

START-OF-SELECTION.
  " 1) 데이터 조회 (classic Open SQL)
  SELECT * FROM sflight INTO TABLE gt_flight.

  " 2) SALV 객체 생성
  TRY.
      cl_salv_table=>factory(
        IMPORTING r_salv_table = go_alv
        CHANGING  t_table      = gt_flight ).

      " 3) 표준 기능 + 표시
      go_alv->get_functions( )->set_all( abap_true ).
      go_alv->display( ).
    CATCH cx_salv_msg.
      MESSAGE 'ALV 생성 실패' TYPE 'I'.
  ENDTRY.

실행(F8)하면 정렬·필터·엑셀 내보내기가 되는 표 리포트가 뜬다. 첫 "쓸 만한" 리포트의 완성이다.

⚠️ 위 SELECT *는 학습용 형태다. 조건을 안 붙였으니 그 테이블의 모든 행을, *니까 모든 컬럼을 로 끌어온다. 연습용 SFLIGHT는 몇백 건이라 괜찮지만 실무 테이블은 수백만 건인 경우가 흔해서, 그대로 실행하면 화면이 한참 멎는다. 실제로는 WHERE carrid = 'LH'처럼 범위를 좁히거나(Chapter 08 · WHERE 상세), UP TO 100 ROWS로 건수를 끊는다(Chapter 08 · SELECT 형태).

조회 결과가 비었을 때

SELECT가 한 건도 못 찾으면 빈 이 그대로 로 넘어가 빈 표가 뜬다. 오류는 아니지만, 쓰는 사람은 "고장 났나?" 하게 된다. 행 수를 세어 0이면 안내 메시지를 띄우고 끝내자.

DATA gv_count TYPE i.    " 위 DATA: 목록에 함께 선언한다

" SELECT 바로 다음에 끼운다
DESCRIBE TABLE gt_flight LINES gv_count.
IF gv_count = 0.
  MESSAGE '조회된 운항편이 없습니다.' TYPE 'I'.
  RETURN.                " 표를 띄우지 않고 여기서 끝낸다
ENDIF.

DESCRIBE TABLE ... LINES는 Chapter 06 · Internal Table 기초에서 행 수를 셀 때 쓴 그 명령이다.

직접 해 보기

SELECT → 행 수 확인 → factory → set_all → display 순서로 눌러, 데이터가 DB→→화면으로 흘러가는 걸 보자. 단계를 건너뛰면 무엇이 빠졌는지 알려 준다.

흔한 실수와 점검

  • 조회 결과 미확인 → 빈 테이블이면 빈 표가 뜬다. 위 DESCRIBE TABLE·IF 점검을 넣자.
  • 인터넷 예제의 @ → 검색하다 보면 INTO TABLE @gt_flight처럼 @가 붙은 SELECT를 만난다. 그건 나중에 배울 새 표기다. 지금은 위 코드처럼 @ 없이 쓴다.

첫 표 리포트가 완성됐다. 다음 레슨에서는 여기까지가 1차의 범위임을 정리하고, 색·편집·이벤트 같은 심화는 각각 어디서 배우는지 한 장에 모아 둔다 → SALV 1차 정리.
