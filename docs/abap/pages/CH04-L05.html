연산자와 흐름 제어

DO / WHILE · 루프 제어

같은 일을 되풀이하고, 멈추고, 건너뛴다.

Track 1Chapter 4Lesson 5입문

같은 일을 9번 반복하려면?

2단을 출력하려면 WRITE를 9번 복붙하면 된다. 하지만 2단부터 9단까지 전부면 72줄을 복붙해야 한다. 사람이 할 짓이 아니다. 반복을 컴퓨터에 맡기는 게 ·이다.

DO — 정해진 횟수만큼

DO n TIMES.는 안쪽을 n번 반복하고 ENDDO로 닫는다. 지금 몇 번째 반복인지는 시스템이 에 자동으로 넣어 준다(1, 2, 3 …).

ABAP
1
2
3
DO 5 TIMES.
  WRITE: / 'sy-index =', sy-index.
ENDDO.

💡 반복 안에 또 반복을 넣으면, 안쪽 루프가 sy-index를 자기 회차로 덮어쓴다. 이 점은 구구단 실습에서 직접 확인한다.

WHILE — 조건이 참인 동안

횟수가 아니라 조건으로 돌릴 땐 을 쓴다. 조건이 거짓이 되면 멈춘다.

ABAP
1
2
3
4
5
6
DATA gv_n TYPE i VALUE 1.

WHILE gv_n <= 5.
  WRITE: / gv_n.
  gv_n = gv_n + 1.     " 이 줄이 없으면 무한루프!
ENDWHILE.

⚠️ WHILE에서는 조건을 언젠가 거짓으로 만드는 코드(gv_n = gv_n + 1)가 반드시 있어야 한다. 없으면 무한루프에 빠진다.

루프 제어 — EXIT · CONTINUE · CHECK

문 뜻
EXIT 지금 도는 반복을 즉시 빠져나간다(반복이 겹쳐 있으면 가장 안쪽 하나만)
CONTINUE 이번 회차만 건너뛰고 다음 회차로
CHECK 조건 조건이 거짓이면 이번 회차를 건너뛴다(CONTINUE의 조건부 버전)

💡 CHECK의 이 뜻은 반복 안에서다. 반복 밖에서 쓰면 "조건이 거짓이면 지금 처리 덩어리를 그만둔다"는 다른 뜻이 되는데, 그 '처리 덩어리'는 뒤의 모듈화 챕터에서 배운다. 지금은 반복 안에서만 쓴다고 알아 두면 된다.

🧑‍💻 다른 언어를 해 봤다면 EXIT가 break, CONTINUE가 continue에 해당하고, CHECK 조건은 "조건이 아니면 continue"를 한 줄로 줄인 것이다. 이름만 다르다.

SY — 시스템이 채워 주는 변수들

처럼 시스템이 자동으로 값을 채워 주는 변수 묶음을 (System Fields)라 한다. 선언 없이 프로그램 어디서나 읽을 수 있다.

이 레슨에서 실제로 쓰는 건 sy-index(현재 반복 회차) 하나다. 나머지는 외워 둘 목록이 아니라, 필요할 때 찾아 쓰는 목록이다. 이런 게 있다는 것만 알아 두자.

자주 보게 되는 SY 변수 목록 (필요할 때 펼쳐 보기)
필드 담긴 값 쓰임 예
sy-index 현재 반복 회차 DO/ 안에서 몇 번째인지
sy-datum 오늘 날짜 날짜 입력칸 기본값
sy-uzeit 현재 시각 처리 시각 기록
sy-uname 로그인 사용자 누가 실행했는지
sy-mandt 로그인한 Client(같은 시스템 안의 독립된 '방') —
sy-langu 로그인 언어 다국어 처리
sy-tcode 현재 어느 화면에서 왔는지
sy-repid 현재 프로그램 이름 로그·메시지
sy-subrc 이 값을 채우는 명령의 성공/실패 0이면 성공(뒤에서 핵심)
ABAP
1
WRITE: / '오늘은', sy-datum, '실행자', sy-uname.

⚠️ SY 변수는 읽어서 쓰는 값이다. 여기에 내 데이터를 저장하면 안 된다(시스템이 언제든 덮어쓴다). 좋은 예는 날짜 입력칸의 기본값을 sy-datum(오늘)으로 주는 식이다.

💡 sy-subrc는 아무 문장이나 채워 주는 값이 아니라, 그 값을 채우도록 정해진 명령 (앞 레슨의 FIND 같은)만 채운다. 그래서 그 명령 바로 다음 줄에서 확인한다. 사이에 다른 문장이 끼면 값이 덮여 엉뚱한 결과를 보게 된다. sy-subrc는 뒤 챕터 (Internal Table·Open SQL)에서 본격적으로 활용한다.

문자열 레슨에서 "FIND의 결과가 어딘가 남는다"고만 하고 미뤄 둔 것이 바로 이 자리다. 이제 읽는 법까지 갖췄으니, 찾았는지 못 찾았는지를 프로그램이 판단할 수 있다. FIND 바로 다음 줄에서 sy-subrc가 0인지 물으면 된다.

ABAP
1
2
3
4
5
6
DATA gv_text TYPE string VALUE 'SAP ABAP'.

FIND 'ABAP' IN gv_text.
IF sy-subrc = 0.        " 0이면 찾았다는 뜻
  WRITE: / '찾았다'.
ENDIF.

흔한 실수와 점검

  • 무한루프 → WHILE 조건을 바꾸는 코드를 빠뜨림. DO n TIMES는 안전.
  • ENDDO/ENDWHILE 짝 → DO는 ENDDO, WHILE은 ENDWHILE.
  • EXIT vs CONTINUE → EXIT=지금 도는 반복에서 탈출(겹쳐 있으면 가장 안쪽 하나만), CONTINUE=이번 회차만 건너뜀.

정리

반복(DO·)과 그 제어(EXIT·CONTINUE·CHECK), 그리고 SY 변수까지 익혔다. 그런데 "반복하는 동안 변수가 정말 1,2,3으로 변하나?"를 눈으로 확인하고 싶다 → 코드를 한 줄씩 멈춰 보는 디버거.
