변수 선언(DATA)

DATA로 값을 담을 그릇, 변수를 선언한다.

Track 1Chapter 2Lesson 1입문

리터럴의 한계

Chapter 1에서 WRITE 'Hello'.처럼 값을 따옴표에 직접 적었다. 이렇게 코드에 값을 그대로 적어 넣은 것을 (literal)이라 한다. 그런데 같은 값을 여러 번 쓰거나, 계산 결과를 보관하려면? 리터럴로는 안 된다. 값을 담아 둘 그릇, 곧 가 필요하다.

DATA로 변수 선언

문으로 변수를 선언한다. 이름 TYPE 타입 형태다.

ABAP
1
2
DATA gv_name TYPE string.
DATA gv_count TYPE i.
  • gv_ 접두어는 관례(global variable). 강제는 아니지만 팀 표준을 따른다.
  • 전역은 "이 프로그램 안 어디서나 보인다"는 뜻이다. 다른 프로그램과 공유된다는 말이 아니라, 한 프로그램 안에서 위에서 선언한 변수를 아래 어느 줄에서든 쓸 수 있다는 뜻이다. 아직 Subroutine(프로그램을 잘게 나누는 단위)을 안 배웠으니 선언하는 변수는 모두 전역이고, 그래서 g로 시작한다. 특정 구간 안에서만 보이는 변수는 lv_(로컬)라 부르는데, 그 이야기는 나중에 한다.
  • TYPE 뒤에 어떤 타입인지 적는다(다음 레슨들의 주제).

🧑‍💻 다른 언어를 해 봤다면 선언과 대입 자체는 낯설지 않다. 지금 모든 변수가 전역인 건 프로그램을 잘게 나누는 법을 아직 안 배워서일 뿐이고, 실무 ABAP도 모듈화한 뒤에는 로컬 변수가 기본이다. 이 레슨에서 새로 챙길 건 사실상 LIKE 하나뿐이니 빠르게 훑고 넘어가도 된다.

값 넣고 출력하기

선언한 변수에 값을 대입(=)하고 출력해 본다.

ABAP
1
2
3
DATA gv_msg TYPE string.
gv_msg = 'Hello, ABAP!'.
WRITE gv_msg.

이제 메시지를 한 곳(gv_msg)에서 관리한다. 바꿀 때 한 줄만 고치면 된다.

선언과 동시에 초기값 — VALUE

=로 나중에 넣는 대신, 선언하면서 바로 초기값을 주려면 VALUE를 붙인다.

ABAP
1
2
DATA gv_qty  TYPE i      VALUE 10.       " 선언과 동시에 10으로 시작
DATA gv_city TYPE string VALUE '서울'.   " 문자열도 같은 방식

VALUE를 안 적으면 변수는 타입의 기본값으로 시작한다. 숫자 타입은 0, 문자 타입은 공백이다. 참고로 뒤에서 배울 N·D·T는 문자형인데도 공백이 아니라 0으로 채워진다(그 타입을 배울 때 다시 짚는다).

ABAP에는 다른 언어의 null(값이 아예 없는 상태) 같은 게 없다. 선언만 해도 이미 빈 값이 들어 있어서, 값을 넣기 전에 읽어도 오류가 나지 않는다.

여러 변수 한 번에 (체인)

콜론(:)으로 를 체인해 여러 변수를 한 번에 선언한다.

ABAP
1
2
3
DATA: gv_first TYPE string,
      gv_last  TYPE string,
      gv_age   TYPE i.

TYPE 말고 LIKE — 기존 변수를 본떠

TYPE 뒤에는 타입 이름을 적지만, LIKE 뒤에는 이미 선언한 변수를 적는다. "저 변수와 똑같은 타입으로 하나 더"라는 뜻이다.

ABAP
1
2
DATA gv_price TYPE i.
DATA gv_total LIKE gv_price.     " gv_price와 같은 타입(i)

가격을 담는 gv_price와 그 합계를 담는 gv_total은 같은 타입이어야 짝이 맞는다. LIKE로 묶어 두면 원본(gv_price)의 타입이 바뀔 때 gv_total도 자동으로 따라 바뀐다. "이 변수와 짝이 되는 변수"를 만들 때 편하다.

흔한 실수와 점검

  • 선언 안 한 변수 사용 → gv_xxx is unknown 오류. 먼저 로 선언.
  • 타입 누락 → DATA gv_x.도 문법상 통과는 된다. 하지만 길이 1짜리 문자(C)로 선언돼 버린다(타입 생략 시의 암묵 기본값). 의도한 게 아니라면 TYPE을 명시한다.
  • LIKE 대상이 아래에 있음 → LIKE는 이미(위에) 선언된 변수만 본뜬다. 참조할 원본을 먼저 선언한다.

정리

  • 값을 코드에 직접 적는 대신, 로 그릇()을 만들어 담는다. 바꿀 곳이 한 곳으로 모인다.
  • 선언은 이름 TYPE 타입 형태. 지금 선언하는 변수는 모두 전역(이 프로그램 안 어디서나 보임)이라 gv_로 시작한다.
  • 선언과 동시에 값을 주려면 VALUE. 안 주면 타입의 기본값(숫자 0·문자 공백)으로 시작한다.
  • 콜론(:) 체인으로 여러 변수를 한 번에 선언한다.
  • TYPE은 타입 이름을, LIKE는 이미 선언한 변수를 본뜬다. 둘 다 참조 대상이 위에 있어야 한다.

값은 담았다. 그런데 TYPE 뒤에 뭘 적나? 타입에는 길이를 안 적어도 되는 것과 적어야 하는 것이 있다. 먼저 전자(Complete) → 다음 레슨.
