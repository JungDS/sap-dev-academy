gt_gugu처럼 같은 모양의 행을 여러 개 담는 그릇이 이다. Chapter 06 · Internal Table 기초에서 APPEND로 한 행씩 채우던 그 그릇에, 이번에는 DB가 대신 채워 준다.

이 한 문장이 정하는 네 가지

방금 문장을 뜯어 보면 SELECT는 결국 네 가지를 정하는 일이다.

  1. FROM — 어느 테이블에서 (zgugudan)
  2. 필드 — 어느 컬럼을 (* = 전부)
  3. WHERE — 어느 행만 (이 문장엔 없다 = 전부. 다음 레슨들에서 다룬다)
  4. INTO — 어디에 담을지 (gt_gugu)
  • 컬럼(column)과 필드(field)는 같은 것을 가리킨다. DB 쪽에서 부를 때 컬럼, ABAP 구조 쪽에서 부를 때 필드라고 하는 습관 차이일 뿐이다.
  • INTO TABLE은 결과 전체를 에 한 번에 채운다. 이렇게 한 번의 왕복으로 여러 행을 통째로 실어 오는 방식을 (배열째 가져오기)라 부른다. 빠르다.
  • 성공 여부는 (0 = 1건 이상), 읽은 행 수는 다.

⚠️ sy-subrc는 예외처럼 튀어나오는 게 아니라 성공·실패가 갈리는 문장이 끝날 때마다 덮어써지는 시스템 필드다. SELECT나 Chapter 06 · 단일 행 제어에서 쓴 READ TABLE처럼 "찾았다/못 찾았다"가 있는 문장이 자기 결과를 여기에 적어 둔다. 그래서 SELECT 바로 다음 줄에서 확인해야 한다. 사이에 그런 문장이 하나라도 끼면 이미 그 문장의 결과로 덮여 있다. 어떤 문장이 값을 남기는지 하나씩 외우기보다 바로 다음 줄에서 확인하는 습관이 안전하다.

📌 이 챕터는 classic 구문이다. Open SQL 표기에는 오래된 classic과 요즘 방식 두 벌이 있는데, 현장 코드 대부분이 아직 classic이라 우리는 이쪽부터 익힌다. 가장 눈에 띄는 차이는 SELECT 뒤에 적는 필드 목록을 콤마 없이 공백으로 나열한다는 점이다(콤마를 넣으면 문법 오류가 난다). 콤마를 빼라는 말은 딱 이 필드 목록에만 해당한다. 뒤 레슨에서 괄호로 묶은 목록 안에 콤마가 보이더라도 그건 classic에서도 원래 쓰는 문법이니 놀라지 말자. 요즘 방식은 Chapter 19 · Modern ABAP SQL에서 따로 배운다. 지금 지킬 건 한 문장 안에 두 방식을 섞지 않는 것 하나뿐이다.

* vs 필드 (projection)

*는 컬럼을 전부 가져오라는 뜻이다. 필요한 컬럼만 골라 적으면 그만큼 덜 실어 오니 빠르다. 이렇게 읽을 컬럼을 골라내는 것을 projection(투영)이라 한다. 사진에서 필요한 부분만 잘라 오는 것과 같다.

ABAP
1
2
3
SELECT dan mul result          " 콤마 없이 공백 구분 (classic)
  FROM zgugudan
  INTO CORRESPONDING FIELDS OF TABLE gt_gugu.

🔎 [선행 사용] INTO CORRESPONDING FIELDS OF TABLE은 "같은 이름 필드끼리 알아서 맞춰 담아라"는 뜻이다. 컬럼을 골라 읽을 때 짝이 되는 표현이라 여기서 미리 썼다. 지금은 분석하거나 외우지 말고 이 짝만 눈에 익혀 두면 되고, 정식으로는 Chapter 08 · INTO 대상 형태에서 배운다.

🔎 여러 테이블을 한 문장에서 함께 읽을 때는 sflight~carrid처럼 물결표로 "어느 테이블의 컬럼인지"를 밝힌다. 지금은 이런 표기가 있다는 것만 알아 두면 된다. 실제로 쓰는 건 테이블을 합쳐 읽는 Chapter 13 · INNER JOIN부터다.

아래 시뮬레이터에서 읽을 컬럼을 골라 보고 조건도 바꿔 보자. 고른 대로 SELECT 문장이 만들어 지고, 그 문장이 어떤 행·어떤 컬럼을 가져오는지 결과 표로 바로 확인할 수 있다.

결과는 반드시 확인

결과
1건 이상 0 읽은 행 수
한 건도 없음 4 0

흔한 실수와 점검

  • 결과 미확인 → 빈 결과일 수 있다. SELECT 바로 다음 줄에서 · 확인.
  • SELECT * 남용 → 큰 테이블을 통째로 읽으면 성능 위험. 필요한 컬럼만 적고 WHERE로 줄인다.

읽을 테이블·필드를 정했다. 그런데 SELECT에는 여러 형태가 있다. 한 건만, 여러 건, 줄여 읽기 → 다음 레슨.
