## 축 라우팅 명기 — 'CH16 상태 R 발명' 실측 적발 (C006, 연계 C012)

- 축 라우팅이 의심 등재한 **'CH16이 상태값 R을 발명'**이 위젯 실측으로 적발됐다: L10 종합 위젯
  (CH16-L10-S01) `DFS_CFG.statuses`가 예약(R)·대기(W)로, 본문 통합 코드 fill_status_list의 **시드 정본
  신규(N)·취소(C)**와 달라 검증표의 '드롭다운 신규 → `gv_stat = 'N'`'을 실행할 수 없고, gv_stat 결과
  표시도 없다. 교정 = 위젯 상태 목록을 정본 N/C로 정렬 + gv_stat 표시.
- **C012(x13 — 챕터 최다 지지)가 같은 계열의 L03분**: 도입 산문 '예약/대기/취소'·해설 불릿 'R/예약'·위젯
  (L03-S01)의 R/W/C가 코드(N/C)와 어긋남. L10 검증표는 코드 쪽과 일치하므로 정렬 대상 = L03 산문·위젯.
