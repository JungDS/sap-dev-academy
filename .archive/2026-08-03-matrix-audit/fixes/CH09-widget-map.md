## 5. 범위 밖 관찰 (수정하지 않음 · 후속 판단용)

1. **`docs/abap/pages/CH09-*.html`가 아직 구 본문 기준** — 본문 작업자가 빌드를 돌리지 않았고(본선 몫) 나도 `docs/**`를 건드리지 않았다. 따라서 `docs`의 L07에는 **`CH09-L07-S03` iframe이 아직 남아 있다**(C014 반영 전 상태). `npm run build:abap` 한 번이면 사라진다 — 위젯 쪽은 그 전후 어느 쪽이든 6단으로 정합돼 있어 깨지지 않는다.
2. **L05 본문(3방식 예시) ↔ L09 과제(Collective 탭 2개)** — L05-S01/S02는 본문대로 3탭·3 Elementary, L09-S01 테스트는 본문 과제대로 "탭 두 개"다. 위젯은 각자 자기 레슨 본문과 정합하지만, 챕터를 통으로 읽으면 `ZSH_CONCERT_COLL`의 구성원이 3개(L05)였다가 2개(L09)로 보인다. **본문 레벨 판단 사항**(위젯에서 임의 통일하지 않음).
3. **`CAPACITY` 값 변경 파급** — L03-S01의 정원을 15000/12000 → 100/50/80(본문 표)으로 맞췄다. 뒤 챕터가 "잔여석" 계산에 이 값을 쓰기 시작하면 여기가 출처가 된다.
4. **`ZCONCERT_T.NAME` 리터럴 신설** — 본문은 "로그인 언어로 각각 채워 두면 된다"까지만 지시하고 값을 주지 않는다. 위젯이 `안유진 단독 콘서트 / ABAP Trio 라이브 / UI5 Night 페스티벌`(+EN 3종)을 쓰기 시작했으므로, 하류가 공연명 리터럴을 참조하려 하면 이 값이 사실상 정본이 된다.
5. **C015(미라우팅)** — 본문 작업자가 남긴 사용자 판단 대기 항목. 위젯과 무관해 손대지 않았다.
