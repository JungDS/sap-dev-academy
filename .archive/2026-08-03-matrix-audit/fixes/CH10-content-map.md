## ★ 위젯 작업자 인계 좌표 (본문 변경으로 기준이 바뀐 항목)

### ★① C002 택1 결과 = **IF/ELSE + abap_true/abap_false** (boolc 제거)

- 선택 이유: 판정 한 줄을 읽으려고 **새 내장 함수(boolc)와 반환형 string→abap_bool 대입**까지 설명하면 입문 부담이 커진다. 이미 배운 `IF/ELSE`만으로 판정이 읽히고, **C027 양수 검증·C053 미존재(-1) 걸러내기가 같은 분기 안에 자연히 들어간다.** (boolc가 R6 위반이 아니라는 판정은 그대로 수용 — 문법 문제가 아니라 학습 부담 때문의 선택이다.)
- 새 판정 조건은 **3항**: `IF iv_want > 0 AND lv_left >= 0 AND iv_want <= lv_left.` → `abap_true` / `ELSE` → `abap_false`.
- `CH10-L07-S02`가 판정식을 텍스트로 보여 준다면 `boolc(...)` 표기를 위 IF/ELSE로 교체. 결과 표시도 참/거짓 대신 **`abap_true`/`abap_false`** 로 쓰면 본문과 완전 일치.

### ★② C013 `gv_` 교정 후 위젯 라벨 정합

본문 전역 위치 변수는 이제 전부 `gv_`다. 위젯이 **FORM/METHOD 밖 변수**를 `lv_`로 표기하는 곳을 함께 고쳐야 챕터 기준이 하나가 된다.

### ★③ L07 코드 변경분 ↔ S01/S02 정합

1. **`get_remaining` sy-subrc 블록이 2줄로 늘고 값이 바뀌었다.** 기존 `cv_left = 0. RETURN.`(1줄) → 현재:
   ```
   IF sy-subrc <> 0.          " 그런 공연이 아예 없다
     cv_left = -1.            " 매진(0)과 구분되는 '없음' 표시
     RETURN.
   ENDIF.
   ```
   **C020**(S01에 sy-subrc 블록 포함) 작업 시 이 4줄을 그대로 실어야 한다. 값이 `0`이 아니라 **`-1`** 인 점 주의 — 스텝 노트도 "공연 없음 = -1"로.
2. **S01 STEPS의 라인 인덱스가 본문 코드와 1:1이어야 한다.** 본문 `get_remaining` 현재 줄 구성: FORM 헤더 4 → 빈줄 → `DATA:` 4 → 빈줄 → `SELECT *` 3 → 빈줄 → `LOOP` 3 → 빈줄 → `SELECT SINGLE` 2 → `IF` 4 → 빈줄 → `cv_left = lv_cap - lv_sum.` → `ENDFORM.`
3. **`can_book`이 1줄 → 5줄(IF/ELSE)로 바뀌었다.** S02가 코드를 렌더한다면 교체. 시그니처(3 USING + 1 CHANGING `abap_bool`)는 **불변** — 하류 `CH16-L10`의 `PERFORM can_book USING … CHANGING …` 호출도 그대로 유효(확인 완료).
4. **C051 재조정** — 과제 문구를 "정원보다 많은" → "**잔여석보다 많은**"으로 고쳤다. 현재 선택지 **5석 > 잔여 4석이면 실패가 이미 시연된다** → '정원 초과 케이스 추가'는 **필수 아님**. 대신 본문 과제 2가 "`0`석으로도 요청해 보자"를 새로 요구하므로, **0석 선택지**를 넣으면 정합이 완벽해진다(선택 사항 — 과제는 SE38 실습이라 위젯 미지원이 결함은 아니다).

## 범위 밖 관찰 (수정하지 않음 · 후속 판단용)

1. **레슨 제목 2건 변경** — `CH10-L04`(정적 기준 → 정적 메서드부터, C047) · `CH10-L06`(Function → Function Module, C021). 타 챕터의 인바운드 링크 14건은 전부 커스텀 링크 텍스트여서 영향 없음을 확인했다(`CH09-L02`·`CH09-L09`·`CH11-L01/L02`·`CH16-L03/L07/L10`·`CH18-L11`·`CH20-L02`·`CH21-L01/L10`·`CH26-L02`·`CH37-L02/L03`). 로드맵·목차가 제목을 캐시한다면 빌드 시 갱신된다.

3. **`STATICS`의 접두어 규약 부재** — R11은 `gv_`/`lv_`만 정의한다. STATICS는 FORM 안 선언이므로 `lv_`를 그대로 썼다(본문 `lv_count`). 별도 접두어(`sv_` 등)를 세울지는 규칙 소관이라 임의로 만들지 않았다.
