## 3. 신규·잔존 핵심 결함 (본선 실측 확정 — 상세 근거는 CHnn-notes.md)

### 필수 교정(코드가 죽거나 학습자가 오진하는 급)
1. **CH10-L04 RETURNING 인라인 완전타입 = 활성화 차단** (CH10-C001, 5벌):
   `RETURNING VALUE(rv_result) TYPE p LENGTH 8 DECIMALS 2.` — 메서드 시그니처 typing 문법에
   LENGTH/DECIMALS 부가어 없음(ABENTYPING_COMPLETE). 콜아웃 문구도 동반 오류.
   **원인 = R1 본선 지시 문구(보강 유발)**. 교정 = `TYPES ty_amount` 경유 + 콜아웃 재서술.
2. **CH11-L02 display 배치 지시 = 덤프 경로** (CH11-C003): "앞의 코드 끝에 한 줄" → ENDTRY 뒤 배치
   유도 → factory 실패 시 초기 참조 display(CX_SY_REF_IS_INITIAL). 교정 = TRY 안 배치(CH12-L07은 이미 정합).
3. **CH11-L06-S01 위젯 데이터 이중 결함** (CH11-C001, 양모델 브라우저 교차 확증):
   라벨·코드 `WHERE C001`인데 C002 행 2건 혼입(Σ 17≠14) + 데이터셋이 관통예제 시드 정본과 불일치
   (0004 배정·이름·상태 상이). 헤더 주석 "본문 정본과 1:1"이 허위화. 교정 = 시드 6건 교체+프리셋 정리.
4. **CH09-L09 ②-3 검증 단계 = 정상 수행자 오진** (CH09-C007): SH 파라미터에 공연명(NAME)이 없는데
   "공연명 나오면 성공" 판정 지시 — 부착 SH가 Check Table 경로를 가림. 교정 = SH 파라미터에
   text table NAME 추가(+판정 문구 정합) 또는 확인 경로 변경.
5. **CH09-L06 VALUE CHECK 예시 자기모순** (CH09-C013): `TYPE zconcert-concert_id`는 FK 없는 마스터
   자기 키 — 본문 스스로 "관계는 zbooking-concert_id에"라 명시(L06:34～36). 교정 = 예시 필드 교체.

### 보강 불완전(잔존)
6. **CH09-L07 사다리에 DE 부착 SH 단 누락** (CH09-C001, 8벌): R1 보강이 6단 재구성하며 DE 단을
   팁으로만 처리 — 팁이 전제하는 단이 사다리·위젯(S01·S02)에 없음. 교정 = Check Table와 고정값 사이 단 삽입.
7. **CH09-L09 감사필드 6개 명세 부재** (CH09-C004): 이름만 나열, DE·타입 없음 — "따라 만들면 돌아간다"
   약속 위반. 교정 = 표준 참조 명세 표 추가(하류 CH25 전제 확인).
8. **CH09-L09 MANDT 서술 사실 오류** (CH09-C003): "Delivery Class를 정하면 자동으로 붙는다" —
   독립 속성 혼동. 표 "(자동)" 표기 동반 정정.
9. **CH09-L09 ②-4 COLL 부착 지시 부재** (CH09-C028) + ZPERF "키 두 칸" 자기모순(C009) +
   ZCONCERT_T 공연명 값 미제시(C052).
10. **CH10 실습 재현성 3건**: L05 `zcl_util` 준비물 부재(C005) · L03 '부르기만' 경계 미선언(C002,
    L05와 비대칭) · L07 FORM→메서드 변환 대응 규칙 부재(C003).
11. **CH11-L04-S01 스텝퍼 상태 결함 2건** (C014·C016): display 후 set_all 성공 처리(L03 교육 역행) ·
    '빈 결과' 버튼의 소급 초기화(스냅샷 의미론 위반).
