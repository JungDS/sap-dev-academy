## 3. 실질 신규·잔존 (수정 후보 — 착수 시 확정)

### 보강 유발·불완전 (배치 5 보강이 원인)
1. **CH17-C001 (x10 확실) — L10 골격 RETURN 논리 결함**: B5 보강이 PBO 경로 E 메시지를 S+`RETURN`으로 교체했는데, FORM(build_fieldcat) 안 RETURN은 그 FORM만 종료 — merge 실패에도 호출자(build_alv)가 layout·display를 이어 실행해 빈 fieldcat으로 표시 호출. 교정 방향: 오류 깃발(예: `gv_error`) + 호출자 분기, 또는 merge 검사 위치 재설계. L04·L07 동형 포함. **R2B5 최중량 — R2B4의 '보강 지시가 만든 결함' 계열 재현.**
2. **CH17-C002 (x7) — L09 준비 코드 과부하**: B5 보강(집계 코드로 재현 가능화)의 트레이드오프 — 색상 레슨의 본문 코드 대부분이 색과 무관한 JOIN·SUM 준비 코드가 됨. 교정 방향: 준비 코드를 `details` 접기/부록화하고 색 관련 줄을 전면에.
3. **CH18-C004 — line_exists 괄호 안 무예외 설명 갭**: B5 보강이 line_exists 보호를 강조하면서, "왜 괄호 안 table expression은 예외가 안 나는가" 설명이 챕터에 없음. 1문단 보충.

### 신규 위젯 결함 (실측 기반·확실)

5. **CH18-C001** — L06 위젯 '12A' 입력에서 CONV '변환 불가'/EXACT '예외' 비대칭 표시 — 본문이 교정하는 오해("CONV 관대")를 위젯이 강화(convI()가 exc 플래그 미설정).
