## 위젯 결함 — 채택 확정급

- **CH11-L06-S01 데이터셋 이중 결함(높음)**: 실측(embeds/abap/CH11-L06-S01.html:70～75) —
  ① 프리셋 라벨 "공연 C001 (6행)"·표시 코드 `WHERE concert_id = 'C001'`(:84)인데 데이터에
  C002 행 2개(0004·0005) 포함 → Σ 17 ≠ C001만 14. 본문 WHERE 교육과 정면 모순
  (AG02 opus·sonnet 양모델 브라우저 실조작 교차 확증).
  ② 데이터셋이 관통예제 시드 정본과 불일치 — 정본(CH12-L03 기대표 역산: C001 4건·N 5건,
  0005 C002 강호동 4 N·0006 C002 차은우 2 C)과 달리 위젯은 0004 C002 유재석 C·0005 C002 김연아 N·
  0006 C001 차은우 5 N. 헤더 주석 "본문 정본과 1:1"(:4)이 허위가 됨.
  교정 = 시드 정본 6건으로 교체 + 프리셋을 "전체(6행)"/"WHERE C001(4행)"로 정리 + 본문 gv_count 서사 정합 확인.
- **CH11-L04-S01 소급 초기화(중간)**: '빈 결과 시나리오' 클릭이 이미 조회·표시된 상태를 소급 재작성
  (gv_count 6→0) — 스냅샷 의미론과 본문 교육 포인트 위반(AG02-s). 엔진 salv-pipeline-stepper.js.
  + display 후 set_all 허용·성공 메시지(AG02-o) — L03 교육(디스플레이 전 설정)과 역순 허용.
- L04 스텝퍼 0행 가드(DESCRIBE→IF→RETURN)가 어떤 경로에서도 결과 차이를 안 만듦(AG02-o) — 검토.

## 수합본(92발견/61클러스터, 높음3·중간22·낮음36) 상위 판정 방향

- **C001 채택**(위 확정 — 위젯 C002 혼입+시드 불일치).
- **C002 채택 후보(중간 하향)**: "IMPORTING=복사, CHANGING=참조" 인과 오류 — ABAP OO 파라미터는
  VALUE() 없으면 IMPORTING도 참조 전달. 교정 = factory 계약(CHANGING T_TABLE)에 맞춘다는 사실 중심
  재서술. 코퍼스: ABENMETHOD_PARAMETERS 계열 확인 후 확정.
- **C003 채택(높음) — 실측 확정**: L02:77 "앞의 코드 끝에 이 한 줄이 더 있어야" + L02:80
  `go_alv->display( ).` — ENDTRY(L02:51) 뒤 배치 유도 → factory 실패(CATCH) 경로에서 초기 참조
  display = CX_SY_REF_IS_INITIAL 덤프. 교정 = display를 TRY 안(factory 다음)으로 지시
  (CH12-L07 캡스톤은 이미 TRY 안 — 하류 정합도 회복). CH11-L06 캡스톤 코드도 동일 점검.
- **C009 기각 방향/C011 원문 확인**: 실측 L02:109～111·L06:69～70 — "미처리 시 구문 검사 경고 +
  런타임 예외 시 덤프" 서술은 CX_STATIC_CHECK 의미론과 일치(cx_salv_msg ← CX_SALV_ERROR ←
  CX_STATIC_CHECK). C009(경고 발생 부정) 기각, 판정서에서 상속 계보 코퍼스 최종 확인.
- **C004 채택(낮음 문구 완화)**: SALV 어원 단정 — "CL_SALV_* 클래스 가족 공통 접두"로 완화(R12 유래
  표기 관례와 정합). x5.
- **C005 채택(P11 계열)**: L02가 L03 해결책(set_all) 코드명까지 선노출 + 시뮬레이터 선조작. x4.
- **C007 채택**: L06 실습 코드의 실행 지점(프로그램·배치) 안내 부재. x3.
- **C012 채택 후보**: L03 SE24 실습에 열어 볼 클래스 이름 미제시.
- C014·C015·C016(위젯 — 위 확정), C022(챕터 intro 보상 부재 — CH10-C035와 동형), 나머지 낮음 36은 통상.
