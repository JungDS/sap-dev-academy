## 수고의 보상을 받을 시간

[[Domain]]·[[Data Element]]를 만드느라 손이 갔다. 그 투자가 **화면에서 한 번에
회수**되는 걸 [[PARAMETERS]]로 체감한다. 앞 두 레슨에서 만든 산출물을 그대로 쓴다.
금액 쪽은 `ZDO_AMOUNT` → `ZDE_AMOUNT`, 상태 쪽은 `ZDO_STATUS` → `ZDE_STATUS`다.

## PARAMETERS — 가장 단순한 입력 화면

[[PARAMETERS]]는 프로그램을 실행하면 **먼저 뜨는 입력 화면에 입력칸 한 개**를 만든다.
이 입력 화면을 ABAP에서는 **선택화면**(Selection Screen)이라 부른다. 프로그램이 일을 시작하기 전에
"무엇을 대상으로 할까"를 사용자에게 물어보는 화면이다. 이 레슨에서는 칸 하나짜리 가장 단순한
선택화면만 다룬다.

> 🧭 **이름이 겹친다** — 여기서 말하는 PARAMETERS는 **선택화면의 입력칸**이다. 다른 언어에서 함수에
> 넘기는 "매개변수(parameter)"와도, 앞 레슨에서 스쳐 본 Parameter ID와도 다른 것이다. 이름만 비슷하다.

```abap
REPORT zdemo_param.

PARAMETERS pa_amt TYPE zde_amount.

WRITE: / '입력값:', pa_amt.
```

실행(F8)하면 **입력 화면이 먼저** 뜨고, 값을 넣고 실행하면 그제야 아래 [[WRITE]]가
돌며 `pa_amt`의 값이 찍힌다.

> ⚠️ **이름은 최대 8자(문법 제한).** PARAMETERS의 이름이 8자를 넘으면 **구문
> 오류**가 난다. 접두어는 SAP 표준 교재 관례인 **`pa_`** 를 따른다. 이 과정의
> 예제도 전부 `pa_`다. 참고로 실무 코드에서는 8자 안에서 한 글자라도 아끼려고
> `p_`로 줄여 쓴 경우도 자주 만난다(같은 관례의 축약형이니 당황하지 말 것).

## 보상 — 라벨과 F4가 따라온다

`pa_amt`의 타입을 [[Data Element]] `zde_amount`로 줬더니 두 가지가 따라온다.

**① 라벨.** 입력칸 옆에 붙는 글자는 프로그램이 따로 들고 있는 **Selection Text**(선택화면 라벨)다.
아무것도 안 하면 이 자리가 비어 있어서 화면에는 `PA_AMT` 같은 기술 이름이 그대로 보인다.
이 Selection Text가 **Data Element의 Field Label을 가져오도록** 체크 한 번만 해 주면, 화면 라벨이
[앞 레슨](CH03-L02.html)에서 채운 "송장 금액"으로 바뀐다.

> 🖱️ **Selection Text 켜는 순서** (SE38에서 프로그램을 연 상태로)
> 1. 메뉴 **Goto → Text Elements → Selection Texts**
> 2. 목록에서 `PA_AMT` 행을 찾는다
> 3. 그 행의 **Dictionary 참조**(Dictionary Reference) 칸에 체크
> 4. 저장하고 프로그램을 **활성화**한 뒤 다시 실행
>
> 이 체크 한 번이 보상의 스위치다. 라벨을 손으로 직접 타이핑해 넣을 수도 있지만, 그러면 나중에
> Data Element의 Field Label을 고쳐도 이 화면은 따라 바뀌지 않는다.

**② [[F4]] 도움말.** Domain에 [[고정값|Fixed Values]]가 있으면 입력칸에서 F4를 눌렀을 때
**선택 목록**이 뜬다. Data Element에 [[Search Help|검색 도움말]]이 연결돼 있어도 마찬가지다.
(Search Help는 F4 목록을 어떤 모습으로 보여 줄지 따로 설계해 두는 DDIC 객체다. 뒤 챕터에서 정식으로 배운다.)

> 이게 "보상"이다. 타입을 `TYPE c LENGTH 8`처럼 줬다면 라벨도 F4도 없다.
> **Data Element로 줬기에** 화면이 똑똑해졌다.

두 보상은 **나오는 곳이 다르다.** 라벨은 Data Element의 **Field Label**에서, F4는 그 아래 Domain의
**Fixed Values**에서 온다. 그래서 고정값이 없는 `zde_amount`(금액)는 라벨만 따라오고,
고정값 O/C를 가진 `zde_status`(예매 상태)는 F4까지 따라온다.

> ⚠️ **단, F4 ≠ 검증.** F4는 *골라 주는 도움말*일 뿐이라, 목록 밖 값을 직접 쳐도
> 기본으로는 **그냥 통과**한다. Domain의 [[고정값|Fixed Values]] 기준으로 **막으려면** 선언에
> `VALUE CHECK`를 붙여야 한다.
>
> `PARAMETERS pa_stat TYPE zde_status VALUE CHECK.`
>
> 단, `VALUE CHECK`는 **DDIC 타입(Data Element)을 참조하는 입력칸에만** 붙일 수 있다.

## 유용한 PARAMETERS 옵션

입력칸에 몇 가지 속성을 더할 수 있다. 먼저 화면을 **편하게** 만드는 셋이다.

```abap
PARAMETERS pa_amt  TYPE zde_amount OBLIGATORY.   " 필수 입력(빈칸이면 거부)
PARAMETERS pa_cnt  TYPE i          DEFAULT 10.   " 화면에 미리 채울 기본값
PARAMETERS pa_name TYPE c LENGTH 20 LOWER CASE.  " 소문자 보존(기본은 대문자 변환)
```

- `OBLIGATORY` — 비워 두면 실행을 막는다(필수).
- `DEFAULT 값` — 화면에 미리 채워지는 기본값.
- `LOWER CASE` — 입력을 대문자로 바꾸지 않고 그대로 둔다.

`LOWER CASE`는 [앞의 Domain 레슨](CH03-L01.html)에서 본 **대소문자(Lower Case) 속성과 같은 이야기**다.
켜는 자리만 다르다. Data Element(→ Domain)를 참조하는 칸이면 **Domain의 대소문자 속성**이 그대로 따라오고,
위 `pa_name`처럼 표준 타입을 직접 준 칸은 참조할 Domain이 없으니 **선언에 `LOWER CASE`** 를 붙인다.

> 🔠 **이건 ABAP 특유다** — 다른 환경의 입력 폼은 보통 친 대로 들어가지만, ABAP 선택화면은
> **가만두면 입력을 대문자로 바꿔 버린다.** 아이디·이메일처럼 대소문자가 살아야 하는 값이면 꼭 확인하자.

**검증은 따로다.** 위 셋은 화면 편의 옵션이고, 값이 맞는지 **막아 주는** 건 다음 하나뿐이다.

```abap
PARAMETERS pa_stat TYPE zde_status VALUE CHECK.  " Domain 고정값으로 입력 검증
```

- `VALUE CHECK` — Domain의 [[고정값|Fixed Values]]와 대조해 **목록 밖 값을 거부**한다.
  DDIC 타입을 참조하는 칸에서만 쓸 수 있다.

## 보상을 직접 확인 — 같은 칸, 두 타입

아래 실험은 **예매 상태 칸**(`pa_stat` · 타입 `zde_status`)으로 한다. 금액과 달리 Domain에 고정값 O/C가
있어서 라벨과 [[F4]]를 한 화면에서 같이 볼 수 있기 때문이다. 같은 입력칸의 타입을
**Data Element ↔ 표준 타입 직접 지정**으로 갈아 끼워 보자. 라벨·F4가 붙었다 떨어지고,
**검증은 `VALUE CHECK` 스위치가 따로**라는 것까지 한눈에 보인다.
F4 목록 밖 값(`X`)을 넣고 `VALUE CHECK`를 껐다 켜 보라. `OBLIGATORY`·`LOWER CASE`도 함께 실험.

## 흔한 실수와 점검

- **라벨이 안 떠요** → Data Element의 Field Label이 비었거나, 타입을 표준 타입으로
  직접 줬거나, Selection Texts 화면의 **Dictionary 참조 체크가 꺼져** 있다(위 순서 참고).
- **F4가 없어요** → Domain에 고정값이 없고, Data Element에 [[Search Help|검색 도움말]]도 없다.
- **목록 밖 값이 그냥 통과해요** → `VALUE CHECK`를 빠뜨린 것이다.
- **PARAMETERS 이름 길이** → 8자 이내(예: `pa_amt`).

## 정리

- [[PARAMETERS]]는 **선택화면(Selection Screen)에 입력칸 한 개**를 만든다. 실행하면 이 화면이 먼저 뜬다.
- 타입을 [[Data Element]]로 주면 **라벨**(Field Label)과 **[[F4]] 목록**(Domain의 [[고정값|Fixed Values]])이 따라온다.
  단 라벨은 Selection Texts에서 **Dictionary 참조 체크 한 번**이 필요하다.
- **F4는 도움말, `VALUE CHECK`가 검증**이다. 둘은 별개 스위치다.
- 옵션은 화면 편의 셋(`OBLIGATORY`·`DEFAULT`·`LOWER CASE`)과 검증 하나(`VALUE CHECK`)로 갈린다.
- 이 챕터의 3계층이 여기서 만난다. **기술 속성은 [[Domain]], 의미·라벨은 [[Data Element]], 화면은 [[PARAMETERS]].**
