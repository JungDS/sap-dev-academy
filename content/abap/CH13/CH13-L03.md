## 묶어서 요약하기

"항공사별 운항편 수", "항공사별 예약 좌석 합계"처럼 **그룹마다 요약**하고 싶다. `GROUP BY`와
[[Aggregate]](집계 함수)다.

## GROUP BY + 집계 (classic)

```abap
SELECT carrid COUNT( * ) AS cnt SUM( seatsocc ) AS total
  FROM sflight
  INTO CORRESPONDING FIELDS OF TABLE gt_sum
  GROUP BY carrid.
```

- 집계 함수: `COUNT( * )`, `SUM( )`, `MAX( )`, `MIN( )`, `AVG( )`.
- **그룹 키가 아닌 컬럼**은 집계 함수로 감싸야 한다(GROUP BY에 없는 평컬럼 금지).
- 결과 구조에 `cnt`, `total` 같은 별칭 필드를 둔다.

## 결과 받기

`INTO CORRESPONDING FIELDS OF TABLE`로 별칭과 같은 이름 필드에 담는다(합계가 커질
수 있으니 타입을 충분히 크게).

## 중복 없이 — `SELECT DISTINCT`

집계까지 필요 없고 **중복 행만 제거**하고 싶을 땐 `DISTINCT`를 쓴다.

```abap
SELECT DISTINCT carrid
  FROM sflight
  INTO TABLE gt_carr.        " 등장한 항공사 코드를 중복 없이
```

`GROUP BY`가 "묶어서 **요약(집계)**"이라면, `DISTINCT`는 "**중복 행만** 제거"다.

## 직접 묶어 보기

그룹 키를 바꾸면 결과 행 수가 어떻게 달라지는지, GROUP BY와 DISTINCT가 어떻게
다른지 직접 확인해 보자.

::embed CH13-L03-S01 | 행 묶기 실험실 (GROUP BY ↔ DISTINCT)::

## 흔한 실수와 점검

- **그룹키 아닌 평컬럼 SELECT** → 오류. 집계로 감싸거나 GROUP BY에 추가.
- **합계 오버플로** → SUM 결과 타입(P 길이)을 충분히.
- **콤마/@** → classic이라 공백 구분, `@` 없이.
