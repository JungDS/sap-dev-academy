## 기능 켜고 띄우기

factory로 만든 [[SALV]] 객체에 **표준 툴바**(정렬·필터·합계·엑셀 등)를 켜고,
`display( )`로 화면에 그린다.

## 표준 Function 켜기

```abap
lo_alv->get_functions( )->set_all( abap_true ).
```

- `get_functions( )`가 기능 객체를 주고, `set_all( abap_true )`로 표준 버튼을 모두 켠다.
- 이 한 줄로 정렬·필터·합계·레이아웃·엑셀 내보내기가 툴바에 생긴다.

## 화면에 표시 — display

```abap
lo_alv->display( ).
```

- `display( )`가 실제로 ALV 화면을 그린다. **이게 없으면 아무것도 안 보인다.**

## 다 켜는 게 항상 답은 아니다

교육에서는 `set_all`로 전부 켜는 게 빠르지만, 실무 화면에서는 **선별**이 흔하다.
저장(레이아웃 변경 저장)이나 엑셀 내보내기를 아무에게나 열면 곤란한 화면도 있기
때문이다. 기능 객체에는 `set_all` 말고 개별 스위치(정렬만, 필터만)도 있다는 것,
그리고 "어떤 버튼을 열지"도 화면 설계의 일부라는 감각만 챙기자(개별 스위치의
이름들은 필요할 때 ADT에서 찾으면 된다).

## 직접 해 보기

기능 켜기(`set_all`)와 화면 표시(`display`)가 별개임을 버튼으로 확인해 보자. `display`를 빼면 어떻게 되는지도.

::embed CH11-L03-S01 | SALV 표준 기능 스위치 — set_all ≠ display::

## 흔한 실수와 점검

- **display 누락** → 객체만 만들고 안 띄움. 가장 흔한 "왜 안 보이지".
- **set_all 안 함** → 표는 떠도 툴바 기능이 비어 보인다.
