## 어디까지가 'SALV 1차'인가

[[SALV]]는 더 많은 걸 할 수 있다. 하지만 지금(1차)은 **읽기 전용 기본 표시 + 표준
Function**까지만 다룬다. 한 번에 다 배우는 대신, 그 기능이 필요해지는 시점에 한 겹씩 더
쌓아 가는 방식이다.

## 지금(1차) 범위

- `factory`로 [[Internal Table]] 표시
- `set_all`로 표준 툴바(정렬·필터·합계·엑셀) 켜기
- `display`로 화면에 출력

## 뒤로 미루는 심화

| 항목 | 어디서 |
|---|---|
| 컬럼 제목·너비, 통화·수량 포맷 세밀 제어 | [SALV 표시 심화](CH22-L01.html) |
| 셀 색·줄 색, [[Hotspot]](누르는 링크처럼 보이는 셀) | [SALV 표시 심화](CH22-L01.html) |
| 더블클릭·툴바 버튼에 반응하기 | [ALV 이벤트](CH30-L01.html) |
| 셀 **편집** | [Editable Grid ALV](CH31-L01.html) |
| 화면 한쪽에 표를 끼워 넣기(컨테이너) | [Grid ALV](CH17-L01.html) |

마지막 줄은 설명이 조금 더 필요하다. **컨테이너**란 화면 안에서 표가 들어앉을 자리를
말한다. 지금까지처럼 표가 화면 전체를 차지하는 게 아니라, 위쪽에는 입력란을 두고 아래쪽에
표를 붙이는 식이다. 사실 SALV로도 컨테이너에 표를 그릴 수 있다. 다만 그러려면 화면을 직접
만드는 이야기가 함께 필요해서, 이 과정에서는 [Grid ALV](CH17-L01.html) 쪽에 모아 뒀다.
**도구의 한계가 아니라 배우는 순서의 문제다.**

## 왜 나눴나

처음부터 모든 ALV 기능을 던지면 압도된다. "결과를 보기 좋게"라는 **지금의 불편**만
해결하고, 색·편집·이벤트는 각자의 불편이 생길 때 배운다.

## 흔한 오해와 점검

- **SALV로 전부 해결하려 한다** → 셀 편집이나 복잡한 이벤트 처리는 Grid ALV의 몫이다.
  도구를 구분해서 쓰자.
- **심화를 지금 다 배우려 한다** → 1차는 "표로 띄우기"까지다. 나머지는 그 기능이
  필요해지는 챕터에서 배운다.
