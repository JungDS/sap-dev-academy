## 선언할 수 없는 변수

지금까지는 **이미 존재하는** 데이터에 이름표를 붙였다. 그런데 이런 요구가 있다.

- 사용자가 DDIC 구조 이름을 고르면 **그 타입의 빈 데이터**를 만들어야 한다.
- 범용 업로드 도구가 파일 헤더를 보고 구조를 만들어야 한다.

타입이 실행 시점에 정해지니 `DATA gs_booking TYPE ts_booking`처럼 **컴파일 시점에 선언할 수
없다**. 실행 중에 데이터를 만드는 문법이 [[CREATE DATA]]이고, 그 이름 없는 데이터를 붙잡는
손잡이가 [[Data Reference]](`REF TO data`)다.

## 무엇인가 — 만들고, 잡고, 풀어서 쓴다

```abap
DATA gr_data TYPE REF TO data.       " 손잡이(어떤 데이터든 가리킬 수 있음)

CREATE DATA gr_data TYPE ts_booking. " 실행 중에 이름 없는 데이터 생성

ASSIGN gr_data->* TO FIELD-SYMBOL(<ls_data>) ELSE UNASSIGN.
```

흐름은 항상 세 단계다.

```text
CREATE DATA        →  reference가 이름 없는 데이터를 가리킴
ASSIGN dref->*     →  Field Symbol이 그 내용물을 가리킴
ASSIGN COMPONENT   →  (구조라면) 내부 필드 접근
```

`gr_data->*`의 `->*`는 **역참조**(reference가 가리키는 *내용물 그 자체*)다. 이름 없는
데이터는 `gr_data-status`처럼 직접 접근하지 않고, 역참조를 Field Symbol에 붙여 다룬다.

## 공장을 돌려 보기

타입을 골라 CREATE DATA → 역참조 → 필드 접근까지 눌러 보라. 없는 타입 이름
(`UNKNOWN_TYPE`)이면 **예외**로 실패하는 것도(sy-subrc가 아니다!) 확인해 보라.

## 어떻게 확인하는가 — 동적 타입 이름

타입 이름을 문자열로 받을 수도 있다. 이때 실패는 `sy-subrc`가 아니라 **예외**다
([TRY/CATCH](CH21-L06.html)).

```abap
DATA gr_any TYPE REF TO data.
DATA gv_type_name TYPE string VALUE 'SYST'.

TRY.
    CREATE DATA gr_any TYPE (gv_type_name).
  CATCH cx_sy_create_data_error INTO DATA(lx_create).
    WRITE / lx_create->get_text( ).
    RETURN.
ENDTRY.

ASSIGN gr_any->* TO FIELD-SYMBOL(<ls_any>) ELSE UNASSIGN.
```

그리고 [다음 레슨](CH28-L07.html)의 RTTS가 만든 "타입 설명서"를 그대로 넘기는 연결점이
`TYPE HANDLE`이다 — 이름 문자열 없이 타입 설명 객체로 데이터를 만든다.

```abap
DATA(lo_type) = CAST cl_abap_datadescr(
  cl_abap_typedescr=>describe_by_name( 'SYST' ) ).

CREATE DATA gr_data TYPE HANDLE lo_type.
```

## 흔한 실수와 점검 🚧

- **`CREATE DATA` 실패를 `sy-subrc`로 확인** → 이 문법의 실패는 **예외**다. `TRY/CATCH`로 받는다.
- **타입 이름 사용자 입력 직결** → `TYPE (이름)`도 [앞 레슨](CH28-L05.html)과 같은 원칙 —
  허용 타입 목록을 둔다.
- **reference가 initial인데 역참조** → `ASSIGN gr_data->*`가 실패한다(`sy-subrc = 4`).
  CREATE 성공 여부부터.
- **"이름이 없으니 금방 사라진다" 오해** → reference나 Field Symbol이 가리키는 동안 그
  데이터는 살아 있다.

## 정리 📌

- 실행 중 데이터 생성 = `CREATE DATA`(만들기) + `REF TO data`(잡기) + `dref->*`(풀어서 쓰기).
- 동적 타입 이름의 실패는 **예외**(`cx_sy_create_data_error`) — `TRY/CATCH`가 기본.
- `TYPE HANDLE` = RTTS 타입 설명서를 CREATE DATA에 꽂는 연결점(다음 레슨에서 그 설명서를 읽는다).

설명서를 읽는 [RTTS](CH28-L07.html).
