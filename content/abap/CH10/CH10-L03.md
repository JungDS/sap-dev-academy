## 프로그램을 넘어 재사용

[[Subroutine]]은 한 프로그램 안에 갇힌다. 여러 프로그램이 **공유**하는 재사용
블록이 [[Function Module]](함수 모듈)이다. `SE37`에서 만들고 관리한다.

## CALL FUNCTION — 호출 구조

```abap
DATA gv_out TYPE p LENGTH 8 DECIMALS 2.

CALL FUNCTION 'Z_ADD_TAX'
  EXPORTING
    iv_amount = 1000          " 넘겨줄 값
  IMPORTING
    ev_result = gv_out        " 돌려받을 값
  EXCEPTIONS
    invalid   = 1
    OTHERS    = 2.

IF sy-subrc <> 0.
  WRITE: / '함수 호출 실패 — sy-subrc =', sy-subrc.
ENDIF.
```

- **EXPORTING** — 함수에 **넘기는** 값(호출자 입장).
- **IMPORTING** — 함수에서 **돌려받는** 값.
- **CHANGING** — 넘겼다가 **수정되어 돌아오는** 값(입출력).
- **TABLES** — [[Internal Table]] 전달(레거시 방식).
- **EXCEPTIONS** — 오류를 `sy-subrc`로 받는다(바로 아래에서 자세히).

> 방향이 헷갈린다: 호출문의 EXPORTING/IMPORTING은 **호출자 기준**이다. 내가 함수로
> EXPORT(내보냄) → 함수가 받음. 반대로 `SE37`에서 **함수 자신을 정의하는 화면**은
> 함수 기준이라 이름이 뒤집혀 보인다. 내가 EXPORTING으로 넘긴 값이 정의 화면에서는
> Import 탭에 들어 있다. 한쪽이 내보내면 다른 쪽이 받는 것이니 뒤집히는 게 정상이다.

## 오류를 번호로 받기 — EXCEPTIONS

`EXCEPTIONS` 절은 함수가 알려 오는 오류 이름에 **번호를 붙이는** 곳이다.
`invalid = 1`은 "invalid 오류가 나면 `sy-subrc`를 1로 채워 달라"는 뜻이고,
`OTHERS = 2`는 "여기 적지 않은 나머지 오류는 전부 2로"라는 뜻이다. 번호는 우리가
정한다.

- **안 적으면 프로그램이 죽는다** — 함수가 일으킨 오류를 `EXCEPTIONS`에 하나도 적지
  않으면 `sy-subrc`로 오지 않고 그 자리에서 런타임 오류(덤프)로 멈춘다.
- **적어 놓고 안 보면 소용없다** — 이 방식은 오류를 **번호로 돌려주기만** 한다.
  저절로 위로 전달되지 않으니 호출 **바로 다음 줄**에서 `sy-subrc`를 확인해야 한다.
- `OTHERS`를 마지막에 하나 두면 예상 못 한 오류까지 걸러진다.

## 어디서 찾나

직접 만들지 않아도 되는 표준 함수가 이미 많다. `SE37` 첫 화면에서 이름이나 설명으로
검색하면 되고, 찾은 함수를 열면 어떤 값을 주고받는지(Import·Export·Exceptions 탭)
바로 볼 수 있다. 그중 업무 처리의 표준 창구로 SAP이 제공하는 것을
[[BAPI]](Business Application Programming Interface)라 부르고, 다른 시스템이 원격으로
부를 수 있게 만든 것을 [[RFC]](Remote Function Call, 원격 함수 호출)라 한다. 둘 다
[Chapter 33 · 인터페이스 실무](CH33-L01.html)에서 본격적으로 다룬다.
