## 화면 글자를 코드에 박으면 생기는 문제

`WRITE '금액'.`처럼 화면에 보일 텍스트를 코드에 직접 적으면, **영어 사용자가
로그인해도 여전히** '금액'이라고 나온다. SAP는 전 세계가 같은 프로그램을 각자
언어로 쓰는 시스템이라, 화면 텍스트는 **언어마다 바뀔 수 있어야** 한다. 그 장치가
[[Text Symbol]](텍스트 심볼)이다.

## 텍스트를 번호로 빼기 — TEXT-nnn

화면 텍스트를 코드에 직접 두지 않고, **세 자리 번호**로 관리한다. 코드에서는
`TEXT-001`처럼 부르고, 실제 글자("금액")는 별도의 텍스트 목록(SE38의 Text Elements)에
등록한다.

```abap
DATA gv_amt TYPE p LENGTH 8 DECIMALS 2 VALUE '1500.00'.

WRITE: / TEXT-001, gv_amt.     " TEXT-001 = '금액'(한국어) / 'Amount'(영어)
```

로그인 언어가 한국어면 '금액', 영어면 'Amount'가 자동으로 나온다. 코드는 그대로다.

> 💡 **등록은 한 언어씩** — SE38의 Text Elements에는 그 프로그램의 **원본 언어**(내가 만들 때
> 로그온한 언어) 한 벌만 등록한다. 다른 언어 번역은 번역 전용 도구(SE63)로 따로 채워 넣는
> 별도의 작업이다. 우리는 지금 원본 언어 한 벌만 등록해 보면 된다.

## 실제로 등록해 보기

번호만 코드에 적어 두면 화면엔 아무것도 안 나온다. 글자를 등록하는 곳은 따로 있다.

1. **SE38**에서 내 프로그램을 연다.
2. 메뉴 **Goto → Text Elements → Text Symbols**를 고른다.
3. 목록의 **Sym** 칸에 `001`, **Text** 칸에 `금액`을 입력한다.
4. **저장**하고 **활성화**한다.
5. 프로그램을 실행하면 `TEXT-001` 자리에 '금액'이 찍힌다.

## `TEXT-001`과 `'금액'(001)`의 차이 (중요)

두 가지로 적을 수 있는데 동작이 다르다.

| 적는 법 | 번역이 없을 때 | 효과 |
|---|---|---|
| `TEXT-001` | **공백**이 나온다 | 번역 누락이 화면에서 바로 들통남 |
| `'금액'(001)` | **'금액'**(괄호 앞 기본값)이 나온다 | 번역이 없어도 일단 보이지만, 누락이 숨겨짐 |

`'금액'(001)`은 기본값('금액')과 번호(001)를 함께 적는 방식이다. 번역을 빠뜨려도
한국어가 보여 편하지만, **누락을 놓치기 쉽다.** 번역 관리를 엄격히 하려면 `TEXT-001`
쪽이 안전하다.

> ⚠️ **등록된 글자가 리터럴을 이긴다** — 001번이 Text Elements에 등록돼 있으면, 화면에는
> 언제나 **등록된 글자**가 나온다. 소스의 `'금액'` 부분만 고쳐 봤자 화면은 그대로다. 글자를
> 바꾸려면 Text Elements에서 001번을 고쳐야 한다. 유지보수에서 자주 걸리는 지점이다.

## 흔한 실수와 점검

- **번호만 적고 등록 안 함** → `TEXT-001`만 쓰고 Text Elements에 안 넣으면 공백.
- **메시지와 혼동** → 사용자에게 띄우는 알림(MESSAGE)은 또 다른 장치이고,
  [Chapter 15 · 입력 검증과 메시지](CH15-L04.html)에서 정식으로 다룬다.
  Text Symbol은 **화면에 박히는 라벨·제목** 용도다.
- **세 자리 번호** → `TEXT-1`이 아니라 `TEXT-001`.
